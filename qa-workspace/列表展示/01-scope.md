## 锚点清单
（PRD 已有编号的直接用原文编号；无编号段落按 M<模块号>-S<章节点号>-P<条目序号> 建锚，条目摘要注明 PRD 位置；摘录均为 ≤40 字连续原句）
| 锚点 | 条目摘要 | 原文摘录 |
|---|---|---|
| GOAL-03 | 承接目标：列表+高级搜索+三快捷筛选 | 支持多维度高级搜索以及"全部、我创建的、待我审核的"快捷筛选 |
| BR-LIST-01 | 默认视图：全部视图按可见权限过滤 | "全部"视图是默认入口，必须按用户可见权限过滤，不可越权看到无权限风险 |
| BR-LIST-02 | 快捷筛选语义：审核人=当前用户且待审核 | "待我审核的"以审核人字段=当前用户且状态为"待审核"为准 |
| BR-LIST-03 | 高级搜索八项固定维度 | 风险内容、分类、来源、级别、状态、处理人、审核人、创建时间共八项 |
| BR-LIST-04 | 数据新鲜度：最新落库值含回写补同步 | 必须来自本系统最新落库值（含回写和补同步），不允许缓存导致明显过期 |
| BR-LIST-05 | 只读约束：本功能不提供修改入口 | 本功能仅负责查询、筛选和详情展示，不提供修改风险主数据的操作入口 |
| BR-LIST-06 | 详情完整性：必填+附件+状态+处理进展 | 六项必填信息 + 附件 + 当前状态 + 处理进展（处理状态、应对措施、实际影响） |
| M1-S32-P3 | 3.2（三）业务范围：我创建的语义 | "我创建的"仅展示当前用户创建的风险 |
| M1-S43-P1 | 4.3 触发事件：进入列表页/切换筛选/组合搜索 | 用户进入风险列表页、切换快捷筛选、组合高级搜索条件 |
| M1-S62-P1 | 6章 FUNC-02 业务流程：权限过滤+分页展示 | 按当前用户的可见权限返回可访问的风险记录，分页展示 |
| M1-S62-P2 | 6章 FUNC-02 业务流程：内容模糊+时间区间 | 风险内容（模糊）、分类、来源、级别、状态、处理人、审核人、创建时间区间 |
| M1-S62-P3 | 6章 FUNC-02 业务界面：部分列排序 | 最近更新时间等列，支持部分列排序 |
| M1-S62-P4 | 6章 FUNC-02 业务界面：详情时间线时间戳 | 时间线区（创建、提交、审核、推送、回写、关闭等关键节点时间戳） |
| M1-S62-P5 | 6章 FUNC-02 业务界面：详情页操作区修改入口约束 | 其余情况无修改入口 |
| FUNC-01 | 引用链：列表数据反映登记结果 | 列表数据始终反映 FUNC-01 登记、FUNC-03 审核（含自动联动推送） |
| FUNC-03 | 引用链+入口归属：审核按钮条件显示 | 仅在满足 FUNC-03 审核条件时显示审核按钮 |
| FUNC-04 | 引用链+入口归属：编辑入口在 FUNC-04 定义 | 编辑/复制/删除分别在 FUNC-04/FUNC-05/FUNC-06 定义 |
| FUNC-05 | 引用链+入口归属：复制入口在 FUNC-05 定义 | 编辑/复制/删除分别在 FUNC-04/FUNC-05/FUNC-06 定义 |
| FUNC-06 | 引用链+入口归属：删除入口在 FUNC-06 定义 | 编辑/复制/删除分别在 FUNC-04/FUNC-05/FUNC-06 定义 |
| FUNC-09 | 引用链：可见权限判定复用 FUNC-09 | 权限判定见 FUNC-09 |
| FUNC-10 | 引用链：列表反映回写后最新状态 | FUNC-10 回写、FUNC-11 补同步后的最新状态 |
| FUNC-11 | 引用链：列表反映补同步后最新状态 | FUNC-11 补同步后的最新状态 |
| NFR-PERF-01 | 横切：搜索与筛选性能方向性要求 | 风险列表高级搜索与快捷筛选在常规数据规模下应能在用户可感知的时间内返回结果 |
| NFR-SEC-01 | 横切：列表/详情可见性遵循平台权限模型 | 用户只能看到其权限范围内的风险记录，不可越权访问他人或他项目的风险 |
| NFR-DATA-04 | 横切：唯一标识全生命周期稳定 | 唯一标识在整个生命周期（登记→审核→推送→回写→补同步→统计消费）中保持稳定 |
