## 锚点清单
| 锚点 | 条目摘要 | 原文摘录 |
|---|---|---|
| GOAL-01 | 承接目标：登记入口、六项必填、附件选填 | 风险内容、分类、来源、级别、处理人、审核人均必填后方可提交，附件选填 |
| 3.2（一）风险登记 | 业务范围：提交后进入待审核并发送提醒 | 提交成功后，风险进入待审核状态，并自动向对应测试管理人发送审核提醒。 |
| 4.1-触发事件 | 触发：测试人员在菜单发起新增风险 | 触发事件：测试人员在项目风险管理菜单发起“新增风险”。 |
| 4.1-前置条件-模块访问 | 前置：测试人员可访问风险管理模块 | 测试人员可访问一体化测试平台（SYS_NEBULA）的项目风险管理模块 |
| 4.1-前置条件-审核人身份 | 前置：审核人须具备测试管理人身份 | 目标审核人具备测试管理人身份或对应审核职责 |
| 4.1-分支-必填项缺失 | 分支：缺失时阻止提交且不进入待审核 | 系统阻止提交并提示缺失字段，风险不进入待审核状态 |
| FUNC-01-流程-校验 | 校验：提示缺失字段，补充后可重新提交 | 缺失时提示具体缺失字段并阻止提交，用户补充后重新提交 |
| FUNC-01-流程-保存 | 保存：初始状态待审核，记录创建人创建时间 | 校验通过后系统保存风险记录，初始状态置为"待审核"，记录创建人、创建时间 |
| BR-RISK-01 | 必填约束：任一缺失不允许提交 | 风险内容、分类、来源、级别、处理人、审核人均必填，任一缺失不允许提交 |
| BR-RISK-02 | 初始状态：唯一为待审核，不可进入其他状态 | 提交成功后风险状态唯一为"待审核"，不可直接进入其他状态。 |
| BR-RISK-03 | 入口收敛：仅模块内统一新增入口 | 本功能仅提供项目风险管理模块内的统一新增入口 |
| BR-RISK-04 | 字典依赖：字典为空或不可用时阻止提交并提示 | 取值来自系统维护的字典，字典为空或不可用时应阻止提交并提示 |
| EXCL-01 | 排除项：不新增工作台审核tab、不汇总其他待审核事项 | 不新增工作台"审核"tab，不汇总冒烟等其他待审核事项 |
| FUNC-01-对象-风险记录 | 主数据关键属性（含唯一标识、创建人、创建时间） | 风险唯一标识、风险内容、分类、来源、级别、处理人、审核人、创建人、创建时间 |
| FUNC-01-对象-风险附件 | 附件对象属性，选填依附于风险记录 | 附件文件名、文件地址、上传时间 |
| FUNC-01-界面-入口 | 入口：模块菜单下的新增风险按钮 | 入口：项目风险管理菜单下的"新增风险"按钮。 |
| FUNC-01-界面-表单 | 表单页：必填缺失时行内或全局错误提示 | 必填字段缺失时的行内或全局错误提示 |
| FUNC-01-界面-成功反馈 | 成功提示语明确，并提供跳转列表入口 | 提示语明确"已提交，等待审核"，并提供跳转列表查看的入口 |
| FUNC-01-标准-附件可选 | 无附件不影响提交成功 | 附件上传可选，无附件不影响提交成功。 |
| FUNC-08 | 引用链：保存成功事件触发审核提醒（被引功能） | 保存成功事件自动触发 FUNC-08 消息提醒 |
| FUNC-03 | 引用链：提交成功记录可被审核功能引用（被引功能） | 可被 FUNC-08 和 FUNC-03 引用 |
| NFR-SEC-05 | 横切：附件上传遵循平台文件类型/大小/安全扫描策略 | 应遵循平台既有的文件类型、大小限制和安全扫描策略 |
| NFR-DATA-04 | 横切：唯一标识全生命周期稳定不得变更 | 唯一标识在整个生命周期（登记→审核→推送→回写→补同步→统计消费）中保持稳定 |
| NFR-OBS-02 | 横切：风险创建等关键事件留可审计时间戳与记录 | 应留有可审计的时间戳和操作记录 |
