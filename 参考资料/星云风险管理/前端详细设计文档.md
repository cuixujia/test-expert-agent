## 1. 背景与目标

当前测试过程中的项目风险分散登记、人工流转，"星云"侧缺少统一的风险列表、检索与详情跟踪入口。本原型承接 FUNC-02 列表展示能力，验证以下目标：

- **GOAL-03**：提供风险列表与检索能力，支持八项高级搜索与"全部 / 我创建的 / 待我审核的"快捷筛选。
- **GOAL-02（展示侧）**：详情页完整呈现审核链路，审核操作受控可见，操作后果通过二次确认明确告知。
- **GOAL-04（展示侧）**：列表与详情的状态、处理进展反映最新落库值（含雪狼回写 FUNC-10 与定时补同步 FUNC-11 之后的数据）。

## 2. 范围界定

### 2.1 本轮范围（2 个 PC 页面）

1. **风险列表页（homePage，系统入口）**
   - 顶部快捷筛选 Tab：全部（默认）/ 我创建的 / 待我审核的；
   - 高级搜索区：八项固定条件 + 查询 / 重置按钮；
   - 列表表格：风险内容摘要、分类、级别、状态、处理人、审核人、创建时间、最近更新时间等列，支持部分列排序；
   - 分页控件；
   - 工具栏导出入口（FUNC-07 演示级）。
2. **风险详情页（riskDetailPage）**
   - 基本信息区：风险内容、分类、来源、级别、处理人、审核人六项必填 + 附件预览 / 下载；
   - 状态与处理进展区：当前状态、处理状态、应对措施、实际影响（雪狼回写字段）；
   - 时间线区：创建、提交、审核、推送、回写、关闭等关键节点时间戳；
   - 操作区：仅当状态为"待审核"且当前用户具备测试管理人身份时显示"通过 / 拒绝"按钮，点击需二次确认弹窗并明确后果。

### 2.2 本轮不做（排除项）

| 编号 | 排除内容 | 说明 |
| --- | --- | --- |
| EXCL-01 | 不新增工作台"审核"tab | 审核入口仅服务于本模块风险详情页 |
| EXCL-02 | 不做推送失败补偿界面 | 本期仅覆盖正常成功路径，不设计重试 / 手动重推 / 异常展示 |
| EXCL-03 | 不展开雪狼平台内部页面 | 雪狼仅作为回写数据来源，Mock 模拟其回写结果 |
| EXCL-04 | 不实现真实权限后台与登录体系 | 用 Mock 模拟"测试人员 / 测试管理人"两种视角切换 |
| EXCL-05 | 不呈现主数据修改入口 | 编辑 / 复制 / 删除等入口不出现（BR-LIST-05） |

## 3. 角色与权限模拟（Mock）

| 视角 | 身份 | 行为差异 |
| --- | --- | --- |
| 测试人员（tester） | 普通用户 | "我创建的"= 创建人为当前用户；无审核按钮；"待我审核的"Tab 数据为空 |
| 测试管理人（manager） | 审核职责用户 | "待我审核的"= 审核人为当前用户且状态为待审核；对待审核风险可见"通过 / 拒绝"按钮 |

- 原型通过页面顶部"模拟身份切换"控件切换视角，请求携带 `X-Mock-Role` 头，Mock 层据此过滤数据与权限表现。
- "全部"视图按用户可见权限过滤（BR-LIST-01），Mock 数据预置可见范围差异（测试人员可见项目内风险，测试管理人可见全部）。

## 4. 页面设计

### 4.1 风险列表页（homePage）

**页面布局（自上而下）**

1. **页头区**：左侧为模块标题"项目风险管理 / 风险列表"；右侧为模拟身份切换控件（测试人员 / 测试管理人）。
2. **快捷筛选 Tab 区**：三个 Tab——全部（默认选中）/ 我创建的 / 待我审核的，各 Tab 带符合当前视角的数量徽标。
3. **高级搜索区**（八项固定条件，BR-LIST-03）：

| 条件 | 控件 | 匹配方式 |
| --- | --- | --- |
| 风险内容 | 文本输入框 | 模糊匹配 |
| 分类 | 下拉单选 | 精确（枚举见 6.2） |
| 来源 | 下拉单选 | 精确（枚举见 6.2） |
| 级别 | 下拉单选 | 精确（高 / 中 / 低） |
| 状态 | 下拉单选 | 精确（5 个状态枚举） |
| 处理人 | 下拉单选（人员） | 精确（Mock 用户列表） |
| 审核人 | 下拉单选（人员） | 精确（Mock 用户列表） |
| 创建时间 | 日期区间选择器 | 起止包含 |

   条件区右侧为"查询""重置"按钮；重置仅清空八项条件，不改变当前 Tab。
4. **工具栏**：右侧"导出"按钮（演示级，见 4.3 节规则）；左侧显示当前结果集统计（共 N 条）。
5. **列表表格**：列依次为——风险内容摘要（可点击）、分类、级别（颜色标签）、状态（颜色标签）、处理人、审核人、创建时间、最近更新时间、操作（"查看详情"）。支持按创建时间、最近更新时间、级别三列排序（升 / 降切换）。
6. **分页控件**：页码、每页条数（10 / 20 / 50）、总条数、跳转。

**交互功能**

- 进入页面默认加载"全部"视图第 1 页（BR-LIST-01）；
- 切换 Tab：重置分页至第 1 页，叠加八项高级条件后重新检索（BR-LIST-02）；
- 点击"查询"：按当前 Tab + 高级条件组合检索；
- 点击"重置"：清空八项条件并恢复默认排序，重新查询；
- 点击风险内容摘要或"查看详情"：跳转风险详情页；
- 点击"导出"：按当前 Tab + 筛选条件生成 Excel 文件并触发浏览器下载，导出内容与页面展示一致（演示级 Mock，不受异步 / 上限约束）；
- 表格行不提供编辑 / 复制 / 删除入口（BR-LIST-05）。

**视觉元素**

- 级别标签配色：高=红色、中=橙色、低=绿色；
- 状态标签配色：待审核=橙色、已审核/待同步=蓝色、处理中=蓝绿色、已关闭（处理完成）=绿色、已关闭（审核拒绝）=灰色；
- Tab 徽标数字、行悬浮高亮、加载 loading 动画、空状态插画与文案（"暂无符合条件的风险"）、接口异常提示条。

### 4.2 风险详情页（riskDetailPage）

**页面布局（自上而下）**

1. **页头区**：左侧"返回风险列表"导航 + 标题"风险详情"；右侧当前状态彩色标签。
2. **基本信息区**：两列字段栅格展示六项必填信息——风险内容（整行）、分类、来源、级别（颜色标签）、处理人、审核人；其下为附件列表（文件名 + 预览 / 下载图标按钮；无附件时显示"无附件"占位）。
3. **状态与处理进展区**：当前状态、处理状态（雪狼回写）、应对措施（雪狼回写）、实际影响（雪狼回写）四个字段；无回写数据时三个回写字段统一显示空态占位"暂无雪狼回写数据"，不得编造状态值（对齐 BR-WALL-04 的空态语义）。
4. **时间线区**：纵向时间线展示关键节点——创建、提交（进入待审核）、审核（通过 / 拒绝 + 审核人）、推送雪狼（推送时间 + 回执标识）、雪狼回写（最近回写时间）、关闭（关闭时间 + 关闭类型）；节点按实际发生时间呈现，未发生的节点不显示。
5. **操作区**：
   - 当且仅当"当前状态 = 待审核"且"当前视角 = 测试管理人"时，显示"通过""拒绝"按钮；
   - 点击任一按钮弹出二次确认弹窗，弹窗正文明确后果：通过 → "审核通过后将自动推送至雪狼平台继续处理"；拒绝 → "拒绝后风险将直接关闭，且不可重新提交"；
   - 确认后调用审核接口，成功后页面刷新为最新状态并给出成功提示（"已通过，等待同步至雪狼" / "已拒绝，风险已关闭"）；
   - 其他状态或视角下操作区不渲染任何修改类按钮，页面整体只读（BR-LIST-05）。

**交互功能**

- 点击"返回风险列表"回到列表页（保留进入前的筛选上下文）；
- 附件预览 / 下载；
- 时间线节点悬浮展示节点详细说明；
- 审核二次确认弹窗支持取消（取消不产生任何状态变更）。

**视觉元素**

- 状态与级别彩色标签（与列表页同色板）、附件图标、时间线圆点节点与连接线（已完成节点实色、未发生节点隐藏）、二次确认弹窗遮罩、成功 / 失败提示条。

### 4.3 页面流转关系

```
风险列表页（homePage，入口）
   ├── 浏览与筛选流程：切换 Tab / 查询 / 重置 / 排序 / 分页（页内动作）
   ├── 高级搜索流程：组合八项条件查询（页内动作）
   ├── 导出流程：点击导出 → 文件下载（页内动作）
   └── 查看风险详情 → 风险详情页（riskDetailPage）
            ├── 返回风险列表 → 回到列表页
            └── 审核操作（测试管理人 + 待审核）：通过 / 拒绝 → 二次确认弹窗 → 状态刷新（页内动作）
```

## 5. 业务规则

### 5.1 列表与检索规则（FUNC-02 核心）

| 编号 | 规则 |
| --- | --- |
| BR-LIST-01 | 默认"全部"视图为入口，必须按当前用户可见权限过滤，不可越权看到无权限风险 |
| BR-LIST-02 | "我创建的"= 创建人字段为当前用户；"待我审核的"= 审核人字段为当前用户且状态为"待审核"；快捷筛选可与八项高级搜索叠加生效 |
| BR-LIST-03 | 高级搜索维度固定为八项：风险内容（模糊）、分类、来源、级别、状态、处理人、审核人、创建时间区间；不得增减核心维度 |
| BR-LIST-04 | 列表与详情展示的状态、处理进展必须来自本系统最新落库值（含雪狼实时回写 FUNC-10 与定时补同步 FUNC-11），不得使用明显过期缓存 |
| BR-LIST-05 | 列表与详情均为只读，不提供修改风险主数据的操作入口；行操作仅允许"查看详情"，编辑 / 复制 / 删除入口一律不呈现 |
| BR-LIST-06 | 详情页必须完整展示：六项必填信息 + 附件 + 当前状态 + 处理进展（处理状态、应对措施、实际影响）+ 关键时间戳 |

### 5.2 关联功能规则（本原型涉及的关联定义）

| 编号 | 规则 | 来源 |
| --- | --- | --- |
| BR-AUDIT-01 | 仅"待审核"状态的风险可被审核；其他状态不展示审核操作入口 | FUNC-03 |
| BR-AUDIT-02 | 每条风险只能产生一次有效审核结论，拒绝后不可重提、不可再审核 | FUNC-03 |
| BR-AUDIT-03 | 审核通过必须自动联动推送至雪狼平台，无人工中间步骤；一条风险只推送一次；推送成功后本地状态保持"已审核/待同步"等待回写 | FUNC-03 |
| BR-AUDIT-04 | 审核拒绝直接进入"已关闭（审核拒绝）"，不推送雪狼 | FUNC-03 |
| BR-AUDIT-05 | 仅具备测试管理人身份的用户可执行审核，无权限用户不可见审核按钮 | FUNC-03 / FUNC-09 |
| BR-EXP-01 | 导出数据与当前筛选条件下的页面展示一致，字段与行集合不偏离 | FUNC-07（演示级） |
| BR-EXP-02 | 导出严格按当前用户可见权限过滤，不越权导出 | FUNC-07 / FUNC-09 |
| BR-WRITE-01 | 处理状态、应对措施、实际影响为雪狼回写的核心字段；关闭标志与关闭时间为关闭场景附加字段 | FUNC-10 |

### 5.3 状态机

```
待审核 ──审核通过──▶ 已审核/待同步 ──雪狼回写──▶ 处理中 ──雪狼关闭──▶ 已关闭（处理完成）
   │
   └──审核拒绝──▶ 已关闭（审核拒绝）［终态，不可重提、不推送雪狼］
```

- 雪狼回写可将"已审核/待同步"直接更新为"处理中"，也可在处理完成时直接置为"已关闭（处理完成）"；
- 定时补同步仅纠正"已关闭"风险的数据，不改变业务处理结论（FUNC-11）。

## 6. 数据模型与枚举定义

### 6.1 风险记录（risk）字段清单

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 风险唯一标识（如 RSK-2026-0001），全生命周期稳定 |
| content | string | 风险内容（列表显示摘要，详情显示全文） |
| category | string | 分类，枚举见 6.2 |
| source | string | 来源，枚举见 6.2 |
| level | string | 级别：high / medium / low |
| status | string | 状态：pending / approved / processing / closed_done / closed_rejected |
| handler | string | 处理人姓名 |
| auditor | string | 审核人姓名 |
| creator | string | 创建人姓名 |
| createTime | string | 创建时间（yyyy-MM-dd HH:mm:ss） |
| updateTime | string | 最近更新时间 |
| auditTime | string \| null | 审核时间 |
| auditResult | string \| null | 审核结论：approve / reject |
| pushTime | string \| null | 推送雪狼时间 |
| pushReceipt | string \| null | 推送回执标识 |
| handleStatus | string \| null | 处理状态（雪狼回写）：to_do / in_progress / resolved |
| measure | string \| null | 应对措施（雪狼回写） |
| impact | string \| null | 实际影响（雪狼回写） |
| closeTime | string \| null | 关闭时间 |
| closeType | string \| null | 关闭类型：done（处理完成）/ rejected（审核拒绝） |
| attachments | array | 附件列表：{ name, url, size, uploadTime }，可为空数组 |
| timeline | array | 时间线节点：{ type: create/submit/audit/push/writeback/close, time, operator, remark } |
| visibleTo | array | 可见范围（Mock 权限用：all / 指定角色集合） |

### 6.2 枚举字典

| 字典 | 取值 |
| --- | --- |
| 分类 | 技术风险 / 需求风险 / 进度风险 / 资源风险 / 外部依赖风险 |
| 来源 | 测试发现 / 代码评审 / 线上问题 / 项目例会 / 人工上报 |
| 级别 | high=高（红色）/ medium=中（橙色）/ low=低（绿色） |
| 状态 | pending=待审核 / approved=已审核·待同步 / processing=处理中 / closed_done=已关闭·处理完成 / closed_rejected=已关闭·审核拒绝 |
| 处理状态（回写） | to_do=待处理 / in_progress=处理中 / resolved=已解决 |

### 6.3 Mock API 设计（vite-plugin-mock，mock/index.js）

所有接口返回 `{ code: 0, data: ... }`；请求头 `X-Mock-Role: tester | manager` 决定视角。

| 接口 | 方法 | 入参 | 出参 data | 覆盖场景 |
| --- | --- | --- | --- | --- |
| /api/risk/list | get | tab（all/mine/audit）、keyword、category、source、level、status、handler、auditor、startDate、endDate、sortField、sortOrder、page、pageSize | { list, total, page, pageSize, tabCounts: { all, mine, audit } } | 列表查询、快捷筛选叠加、排序、分页 |
| /api/risk/detail | get | id | 风险记录全字段（含 timeline、attachments、回写字段） | 详情展示 |
| /api/risk/audit | post | { id, action: 'approve' \| 'reject' } | 更新后的 status、auditTime、pushTime、pushReceipt | 审核通过 / 拒绝（通过自动生成推送回执） |
| /api/risk/export | get | 同列表筛选参数 | 文件流（Excel），或演示级返回导出摘要 | 演示级导出下载 |
| /api/risk/users | get | 无 | { handlers: [...], auditors: [...] } | 处理人 / 审核人下拉选项 |

**Mock 数据要求**

- 总量 ≥ 30 条，支持默认每页 10 条的分页演示（至少 3 页）；
- 覆盖全部 5 种状态：待审核、已审核/待同步、处理中、已关闭（处理完成）、已关闭（审核拒绝），各状态均有代表记录；
- 覆盖 3 种级别、不同创建人 / 审核人（含"测试人员"视角当前用户创建的记录、"测试管理人"视角当前用户为审核人且状态待审核的记录，用于验证 BR-LIST-02）；
- 体现雪狼回写：processing / closed_done 记录必须含处理状态、应对措施、实际影响；部分 approved 及待审核记录回写字段为 null，用于验证详情页空态展示；
- 时间线数据与状态机一致：待审核记录只有 create/submit 节点；closed_done 记录具备完整六节点；
- 列表 / 详情 / 导出使用同一份内存数据源，保证口径一致（BR-LIST-04、BR-EXP-01）。

### 6.4 边界情况设计

| 场景 | 表现 |
| --- | --- |
| 列表加载中 | 表格区域 loading 动画，禁止重复提交查询 |
| 查询结果为空 | 空状态插画 + "暂无符合条件的风险"，提供"重置条件"快捷操作 |
| 接口异常 | 顶部错误提示条"查询失败，请重试"，保留上次有效数据 |
| "待我审核的"无数据（测试人员视角） | 空态文案"当前视角无待审核风险" |
| 详情页无附件 | "无附件"占位 |
| 详情页无雪狼回写数据 | 处理状态 / 应对措施 / 实际影响显示"暂无雪狼回写数据"占位，不编造值 |
| 详情页无审核权限 / 非待审核状态 | 操作区不渲染审核按钮 |
| 审核二次确认取消 | 弹窗关闭，无任何状态变更 |
| 非法 / 不存在的风险 id | 详情页提示"风险不存在或已删除"，提供返回列表入口 |
