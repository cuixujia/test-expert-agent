# FUNC-01 新增风险（XZF）锚点底册

## 锚点清单
| 锚点 | 条目摘要 | 原文摘录 |
|---|---|---|
| GOAL-01 | 承接目标：统一入口登记，必填校验通过后方可进入待审核 | 测试人员可在统一入口完成风险登记，必填项校验通过后方可进入待审核状态 |
| M3-S21-P1 | 3.2 业务范围（一）：测试人员在本模块新增风险 | 测试人员在一体化测试平台的项目风险管理模块中新增风险 |
| M4-S41-P1 | 4.1 参与角色与系统自动行为：必填校验、状态变更、提醒发送 | 参与角色：测试人员、测试管理人；系统自动完成必填校验、状态变更和审核提醒发送 |
| M4-S41-P2 | 4.1 触发事件：在项目风险管理菜单发起"新增风险" | 触发事件：测试人员在项目风险管理菜单发起"新增风险" |
| M4-S41-P3 | 4.1 前置条件①：测试人员可访问本模块 | 测试人员可访问一体化测试平台（SYS_NEBULA）的项目风险管理模块 |
| M4-S41-P4 | 4.1 前置条件②：表单字段字典可用 | 风险表单字段字典（分类、来源、级别等）可用 |
| M4-S41-P5 | 4.1 前置条件③：目标审核人身份/职责要求 | 目标审核人具备测试管理人身份或对应审核职责 |
| M4-S41-P6 | 4.1 分支行为：必填缺失时阻止提交且不进入待审核 | 系统阻止提交并提示缺失字段，风险不进入待审核状态 |
| BR-RISK-01 | FUNC-01 必填约束：六项必填，缺失不允许提交 | 风险内容、分类、来源、级别、处理人、审核人均必填，任一缺失不允许提交 |
| BR-RISK-02 | FUNC-01 初始状态：唯一为"待审核"，不可直接进入其他状态 | 提交成功后风险状态唯一为"待审核"，不可直接进入其他状态 |
| BR-RISK-03 | FUNC-01 入口收敛：仅本模块统一新增入口 | 本功能仅提供项目风险管理模块内的统一新增入口 |
| BR-RISK-04 | FUNC-01 字典依赖：字典空/不可用时阻止提交并提示 | 分类、来源、级别等字段取值来自系统维护的字典，字典为空或不可用时应阻止提交并提示 |
| M6-S601-P1 | FUNC-01 流程：完整性校验缺失阻止提交，补充后重新提交 | 系统对必填项执行完整性校验：缺失时提示具体缺失字段并阻止提交，用户补充后重新提交 |
| M6-S601-P2 | FUNC-01 流程：校验通过保存记录，初始状态待审核并记录创建人/时间 | 校验通过后系统保存风险记录，初始状态置为"待审核"，记录创建人、创建时间。 |
| M6-S601-P3 | FUNC-01 业务对象：风险记录关键字段集 | 风险唯一标识、风险内容、分类、来源、级别、处理人、审核人、创建人、创建时间 |
| M6-S601-P4 | FUNC-01 业务界面：新增风险按钮入口位置 | 入口：项目风险管理菜单下的"新增风险"按钮 |
| M6-S601-P5 | FUNC-01 业务界面：表单页构成（必填字段+附件区+提交/取消） | 风险登记表单页：六项必填字段 + 附件上传区 + 提交/取消操作 |
| M6-S601-P6 | FUNC-01 完成标准：附件可选，无附件不影响提交成功 | 附件上传可选，无附件不影响提交成功 |
| FUNC-08 | 引用链：FUNC-01 保存成功事件自动触发消息提醒（被引功能：消息提醒） | 保存成功事件自动触发 FUNC-08 消息提醒，向指定测试管理人发送审核提醒 |
| FUNC-03 | 引用链：FUNC-01 提交后记录供审核链路引用（被引功能：审核风险） | 后续：FUNC-08（提醒）、FUNC-03（审核后可能编辑/复制/删除） |
| EXCL-01 | 排除项：不新增工作台"审核"tab，不汇总其他待审核事项 | 不新增工作台"审核"tab，不汇总冒烟等其他待审核事项 |
