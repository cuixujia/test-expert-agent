# 需求平台-产品需求说明书PRD-第二稿 功能清单

| 模块编号 | 模块名称 | 功能编号 | 功能名称 | 功能码 | 一句话说明 |
|---|---|---|---|---|---|
| MOD-01 | 风险管理 | FUNC-01 | 新增风险 | XZF | 测试人员在项目风险管理模块统一入口登记风险，六项必填校验通过后保存并进入待审核（功能码沿用已验收产物 XZF-新增风险，不重拟） |
| MOD-01 | 风险管理 | FUNC-02 | 列表展示 | LBZS | 风险列表页默认全部视图按可见权限过滤，支持全部/我创建的/待我审核的快捷筛选、八项高级搜索组合与详情进展查看 |
| MOD-01 | 风险管理 | FUNC-03 | 审核风险 | SHFX | 测试管理人对待审核风险执行通过或拒绝；通过后本功能内自动联动推送雪狼，拒绝后直接关闭且不可重提 |
| MOD-01 | 风险管理 | FUNC-04 | 编辑风险 | BJFX | 对非关闭状态风险修改可编辑字段后重新提交，状态回到待审核等待再次审核 |
| MOD-01 | 风险管理 | FUNC-05 | 复制风险 | FZFX | 基于已有风险预填生成全新独立风险记录，提交后进入待审核，源记录不受影响 |
| MOD-01 | 风险管理 | FUNC-06 | 删除风险 | SCFX | 对允许删除状态（默认仅待审核）风险软删除留痕，已推送雪狼或已流转风险不可删除 |
| MOD-01 | 风险管理 | FUNC-07 | 风险导出 | FXDC | 在风险列表页按当前筛选条件导出 Excel/CSV，内容与页面一致且受可见权限约束 |
| MOD-01 | 风险管理 | FUNC-08 | 消息提醒 | XXTX | 风险登记提交成功后自动向指定测试管理人定向发送审核提醒，发送结果留痕 |
| MOD-01 | 风险管理 | FUNC-09 | 权限控制 | QXKZ | 横切校验风险相关页面与操作的可见数据范围和操作权限，越权在接口层拦截 |
| MOD-02 | 数据同步 | FUNC-10 | 雪狼风险数据实时同步 | XLSS | 接收雪狼端处理状态、应对措施、实际影响实时回写，按风险唯一标识匹配更新并幂等处理 |
| MOD-02 | 数据同步 | FUNC-11 | 雪狼风险数据定时同步 | XLDS | 定时任务对已关闭风险补同步，发现差异以雪狼端为权威源纠正本地并产出运行报告 |
| MOD-03 | 度量 | FUNC-12 | 质量看板 | ZLKB | 质量看板接入项目上报风险统计数据，状态、等级、数量口径与风险主数据一致 |
| MOD-03 | 度量 | FUNC-13 | 二级部看板 | EJKB | 二级部看板接入项目上报风险统计数据，口径与质量看板对齐且与风险主数据一致 |
| MOD-04 | 报表查询 | FUNC-14 | 项目上报风险记录表 | SBJL | 既有报表框架新增项目上报风险记录表，支持按既有查询条件检索和导出 |
| MOD-05 | 项目首页 | FUNC-15 | 近三日风险墙展示 | SFRQ | 近三日风险墙保持原取值规则不变，仅新增风险解决状态和风险等级两列展示 |
| MOD-06 | 项目日报 | FUNC-16 | 日报生成展示 | RBSG | 项目日报双口径取数：今天遇见的问题含当天全量变动风险，历史未解决的问题为此前产生且仍未关闭 |
| MOD-06 | 项目日报 | FUNC-17 | 日报导出 | RBDC | 项目日报按页面展示同一份风险关联数据导出 PDF/Excel 并按项目维度归档留存 |

（本表首次 S1 全量登记后冻结：功能码全局唯一，后续功能开工沿用、不得重拟）
