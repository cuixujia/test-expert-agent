# 定期存款购买（F01）锚点底册

## 锚点清单
| 锚点 | 条目摘要 | 原文摘录 |
|---|---|---|
| 3.2 | 功能范围：产品货架展示、产品详情查看、购买信息录入、利息试算、业务规则校验、利率锁定与起息、到期处理方式选择、推荐人关联、交易提交与结果反馈、异常场景处理共 10 项 | 在个人网银渠道展示可售的普通定期存款产品列表，包括产品名称、存期、年利率、起存金额、剩余额度等关键信息 |
| 3.3 | 排除项：定期定投、代办购买、大额存单、外币定期、支取/提前支取、查询、营销活动管理、手机银行渠道不在本次范围 | 每月自动扣款购买定期的签约功能不在本次范围 |
| 3.4 | 用户范围：已实名认证且证件有效的个人客户；仅个人网银渠道；仅普通定期存款产品 | 目标用户：已实名认证的个人客户，证件在有效期内 |
| 3.5 | 系统职责：个人统一电子渠道系统负责前端展示、业务规则校验、交易提交与结果反馈；核心系统负责账户开立和资金划转；客户经理系统支持推荐人关联和业绩归属 | 本系统负责前端展示、业务规则校验、交易提交与结果反馈 |
| 4.1 | 主流程 E01~E08：进入存款专区、查看详情、选付款账户、输入金额、选存期和到期方式、阅读确认、提交交易、返回结果 | 客户从个人网银首页或理财频道点击"存款专区"或"定期存款"菜单 |
| 4.2.1 | B01 余额不足：可用余额 = 账户余额 - 冻结资金 - 在途资金；阻止提交，提示缺口金额，引导转入或换账户，不提供垫资透支 | 页面提示"余额不足，还差 XX 元"，告知具体缺口金额 |
| 4.2.2 | B02 产品售罄：额度用完或停售时列表页显示标签、详情页禁止购买、提交时提示已售罄；推荐同类在售产品 | 产品卡片显示"今日额度已售罄"或"暂停销售"标签 |
| 4.2.3 | B03 证件过期：限制线上渠道办理存款购买，指引到柜面更新证件 | 您的证件已过期，请先更新证件信息 |
| 4.2.4 | B04 系统超时：超过 30 秒未返回结果时禁止引导重试，后台核实交易状态，失败则解冻退回资金 | 禁止引导客户重试，避免重复扣款造成资金损失 |
| 4.2.5 | B05 触发限额：单户上限、单日限额、II 类户限额触达时拦截并区分类型提示剩余额度 | 明确提示"已超过 XX 限额，当前剩余额度为 XX 元"，告知是哪一类限额及剩余额度 |
| 4.3.1 | R01 利率锁定：按购买时公示挂牌利率锁定合约利率，之后加息降息不影响；当天买入当天起息 | 按购买时银行公示的挂牌利率锁定合约利率 |
| 4.3.2 | R02 到期日计算：到期日 = 起息日 + 存期，按月对月对日推算 | 到期日 = 起息日 + 存期 |
| 4.3.3 | R03 自动转存：到期后按到期日挂牌利率续存同期限，不再适用原利率；转存设置购买后可修改 | 到期后按到期日银行挂牌利率续存同期限 |
| 4.3.4 | R04 合规红线：利率必须锁定、关键信息确认留痕、宣传不能误导、可疑交易不重试、销售可回溯 | 利率必须锁定：客户购买时的利率写入合约，事后不能变更 |
| 4.3.5 | R05 起存金额与递增单位：必须达到最低起存金额并按递增单位递增，不满足不允许提交 | 购买金额必须达到产品规定的最低起存金额（如 50 元起），且按递增单位递增 |
| 4.3.6 | R06 II 类户限额：日累计不超过 1 万元、年累计不超过 20 万元，超出拒绝处理 | II 类户购买定期存款受以下限额约束：日累计不超过 1 万元，年累计不超过 20 万元 |
| 5 | F01 功能矩阵：单一功能包含 10 个子步骤，复用存量功能 FUN202608192089893037232488449 和 FUN202608192089893038520139777 能力 | 将原 10 项功能合并为单一功能 F01"定期存款购买"，作为完整的业务功能单元 |
| 6.1.1 | F01 业务流程详述：10 个子步骤、业务规则、业务对象、业务界面、完成标准 | 个人网银渠道可完整执行定期存款购买流程，从产品浏览到交易完成 |
| 7.1 | 性能要求：产品列表加载 ≤2 秒、利息试算响应 ≤1 秒、交易提交响应 ≤5 秒、并发 ≥1000 用户 | 产品列表页加载时间：≤2 秒 |
| 7.2 | 安全要求：交易前验证实名认证和证件有效期、HTTPS 加密传输、交易留痕、反洗钱筛查 | 所有交易数据采用 HTTPS 加密传输 |
| 7.3 | 可用性要求：系统可用性 ≥99.9%、故障后 30 分钟内恢复、外部系统不可用时明确提示受影响功能 | 系统可用性：≥99.9% |
| 7.4 | 合规要求：II 类户限额严格执行、单笔 ≥5 万元报送大额交易、证件过期限制线上业务、预留双录/视频回溯接口 | 单笔交易≥5 万元须向风险控制系统报送大额交易 |
| 7.5 | 审计要求：交易日志记录请求参数、处理结果、调用链路；操作审计记录关键操作时间戳；异常日志记录错误信息和堆栈 | 完整记录每笔交易的请求参数、处理结果、调用链路 |
| 7.6 | 兼容性要求：支持主流浏览器最新版本；个人网银与手机银行渠道参数隔离互不影响 | 个人网银渠道与手机银行渠道参数隔离，互不影响 |
