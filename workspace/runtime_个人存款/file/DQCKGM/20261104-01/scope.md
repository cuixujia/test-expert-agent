# 定期存款购买 锚点底册

## 锚点清单
| 锚点 | 条目摘要 | 原文摘录 |
|---|---|---|
| 3.1 | 业务目标：提升存款转化率、保障交易安全、改善客户体验、满足合规要求、支持营销联动 | 优化产品货架展示和购买流程，提高从产品浏览到实际购买的转化率 |
| 3.2 | 功能范围：产品货架展示、产品详情查看、购买信息录入等 10 项功能 | 在个人网银渠道展示可售的普通定期存款产品列表 |
| 3.3 | 排除项：定期定投、代办购买、大额存单、外币定期、支取、查询、营销活动管理、手机银行渠道 | 每月自动扣款购买定期的签约功能不在本次范围 |
| 3.4 | 用户范围：已实名认证证件有效的个人客户，仅个人网银渠道，仅普通定期存款产品 | 已实名认证的个人客户，证件在有效期内 |
| 3.5 | 系统职责：本系统负责前端展示、业务规则校验、交易提交与结果反馈 | 本系统负责前端展示、业务规则校验、交易提交与结果反馈 |
| 3.6 | 系统职责矩阵：各系统在 11 个功能环节中的分工 | 个人统一电子渠道系统（SYS_PERBANK） |
| 4.1 | 主流程 E01~E08：进入存款专区至返回交易结果的完整事件链 | 客户从个人网银首页或理财频道点击"存款专区"或"定期存款"菜单 |
| 4.2.1 | B01 余额不足处理：阻止提交并告知缺口金额，引导转入资金或更换账户 | 页面提示"余额不足，还差 XX 元"，告知具体缺口金额 |
| 4.2.2 | B02 产品售罄处理：列表页标签、详情页禁购、提交时提示并推荐同类在售产品 | 列表页实时或定时刷新产品剩余额度 |
| 4.2.3 | B03 证件过期处理：限制线上渠道办理存款购买，指引到柜面更新证件 | 证件过期则限制线上渠道办理存款购买 |
| 4.2.4 | B04 系统处理超时处理：禁止引导重试，后台核实后主动通知客户 | **禁止引导客户重试**，避免重复扣款造成资金损失 |
| 4.2.5 | B05 触发限额处理：拦截超限申请，区分限额类型给出针对性提示 | 明确提示"已超过 XX 限额，当前剩余额度为 XX 元" |
| 4.3.1 | R01 利率锁定规则：按购买时公示挂牌利率锁定，当天买入当天起息 | 按购买时银行公示的挂牌利率锁定合约利率 |
| 4.3.2 | R02 到期日计算规则：到期日=起息日+存期，按月对月对日 | 到期日 = 起息日 + 存期 |
| 4.3.3 | R03 自动转存规则：到期后按到期日挂牌利率续存同期限，设置可修改 | 到期后按到期日银行挂牌利率续存同期限 |
| 4.3.4 | R04 合规红线：利率锁定、确认留痕、宣传不误导、可疑交易不重试、销售可回溯 | 系统超时场景宁可查证，不可引导重复购买造成重复扣款 |
| 4.3.5 | R05 起存金额与递增单位规则：须达最低起存金额且按递增单位递增 | 购买金额必须达到产品规定的最低起存金额 |
| 4.3.6 | R06 II 类户限额规则：日累计不超过 1 万元，年累计不超过 20 万元 | II 类户购买定期存款受以下限额约束：日累计不超过 1 万元，年累计不超过 20 万元 |
| 4.4 | 参与角色：客户、本系统、核心系统、客户经理系统及客户经理、推荐人 | 购买定期存款的个人客户，负责浏览产品、录入信息、确认购买 |
| 4.5 | 业务对象 O01~O07：存款产品、订单、定期账户、客户信息、流水、推荐人、付款账户 | 产品 ID、产品名称、存期、年利率、起存金额、递增单位、单户上限、单日限额、剩余额度 |
| 5 | 功能矩阵：F01 定期存款购买合并 10 个子步骤；复用存量 FUN202608192089893037232488449 等能力 | 原 10 项功能合并为单一功能，因为这些都是同一购买流程的步骤 |
| 6.1.1 | F01 业务流程、业务规则、业务对象、业务界面、完成标准、存量功能编码清单 | 个人网银渠道可完整执行定期存款购买流程，从产品浏览到交易完成 |
| 7.1 | 性能要求：列表页≤2 秒、试算≤1 秒、提交≤5 秒、并发≥1000 用户 | 产品列表页加载时间：≤2 秒 |
| 7.2 | 安全要求：身份验证、HTTPS 加密、交易留痕、反洗钱筛查 | 所有交易数据采用 HTTPS 加密传输 |
| 7.3 | 可用性要求：可用性≥99.9%、故障 30 分钟内恢复、外部系统不可用时明确提示 | 系统可用性：≥99.9% |
| 7.4 | 合规要求：II 类户限额、单笔≥5 万报送大额交易、证件有效期校验、预留双录接口 | 单笔交易≥5 万元须向风险控制系统报送大额交易 |
| 7.5 | 审计要求：交易日志、操作审计、异常日志 | 完整记录每笔交易的请求参数、处理结果、调用链路 |
| 7.6 | 兼容性要求：主流浏览器兼容、网银与手机银行渠道参数隔离 | 支持主流浏览器（Chrome、Firefox、Edge、Safari 最新版本） |
