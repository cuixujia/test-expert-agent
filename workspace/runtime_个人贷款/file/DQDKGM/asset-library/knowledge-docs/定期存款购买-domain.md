# 定期存款购买 业务功能知识

## 一、这个业务是什么

定期存款购买，就是客户把活期账户里的钱转成一笔定期存款：客户挑好一款定期产品（看中它的存期和利率），指定用哪个账户付款、存多少钱，银行把钱从活期划到定期，给客户开立一份定期存款合约，约定好利率、期限、到期日。到期后客户拿回本金和利息。

用大白话说：**客户在银行"下单买了一笔定期"，这个功能就是完成这笔"下单"的全过程。**

它是银行存款销售最核心的交易动作。客户买理财、买基金，绕不开先有存款；银行要拉存款、稳存款，靠的就是这个功能的体验和产品竞争力。转化率（看了产品页的人有多少真正买了）、客单价（平均每笔买多少钱）、复购率（老客户是否持续买入），是业务上衡量这个功能的三个核心指标。

## 二、客户的购买动机

理解客户为什么买定期，有助于理解产品的设计和销售话术：

- **锁定收益**：看中一段确定期限内确定的利息，不想承担理财和基金的波动风险。利率下行周期里，客户倾向于买长期锁定高利率——这也是为什么银行在降息前会迎来定期购买高峰。
- **资金规划**：一笔短期内不用的钱（年底奖、教育金、拆迁款）需要安排去处，定期是最简单省心的选择。
- **比价行为**：客户会货比三家——比不同银行的利率、比同一家银行不同产品的档位。产品页的利率展示和收益试算直接影响客户的决策。
- **营销拉动**：加息券、抽奖、新人礼包、客户经理推荐等营销手段对购买行为有明显的拉动作用。

## 三、产品选择与展示

客户进到购买页面，第一眼看到的是"产品货架"。业务上货架的编排直接影响成交：

- **展示要素**：产品名称、存期、年利率、起存金额、剩余额度（大额存单）。这些信息要一目了然，利率突出显示。
- **排序逻辑**：业务上通常按主推产品、利率高低、营销资源位来排序，配合营销节奏调整。
- **可见性控制**：有的产品只对特定客群可见（如新客专享、代发工资客群专享、养老客群专享），通过白名单控制谁能看到、谁能买。
- **售罄状态**：大额存单这类额度型产品，售罄要明确显示"今日额度已售罄"，并可能提供到货提醒、预约功能。

## 四、购买的业务规则

### 4.1 谁能买

- 已实名认证的正常客户，证件在有效期内（证件过期会限制非柜面渠道办理）。
- 产品有准入客群要求的（白名单产品），客户需在名单内。
- 账户类型会影响购买能力：II 类户存入资金有日累计 1 万、年累计 20 万的限制。

### 4.2 用什么钱买

- 转出账户必须是客户本人名下状态正常的活期账户（借记卡活期或活期存折）。
- 扣的是账户的**可用余额**——不是账面余额，要扣除冻结和在途的钱。
- 支持本人账户购买，也支持特定场景下的代办购买（如子女为父母购买，需验证亲属/监护关系）。

### 4.3 买多少

金额上有一套从产品到客户的约束，业务上要逐条向客户讲清楚：

1. **起存金额**：低于起存金额买不了（如定期 50 元起、大额存单 20 万起）。
2. **递增单位**：部分产品要求金额按固定单位递增（如 1 万元递增）。
3. **单户上限**：同一客户在该产品上最多持有多少。
4. **单日限额**：客户当日累计买入的上限。
5. **余额充足**：购买金额不能超过转出账户的可用余额。

### 4.4 利息怎么定

- 买的那一刻，这笔定期就按当时公示的利率**锁死**了。之后银行降息加息，都不影响这笔已成交的定期——这是定期存款对客户最有价值的承诺。
- 当天买入一般当天起息。
- 到期日按"起息日 + 存期"推算，例如 2026 年 1 月 31 日存一年期，到期日为 2027 年 1 月 31 日。
- 页面上算给客户看的"到期可得利息"是预估展示，实际入账以银行核算为准，展示时要有这个提示。

### 4.5 到了期怎么办

买的时候客户就要选好到期处理方式，这是合约的一部分：

- **不转存**：到期后本息自动回到活期账户，钱"活"了。
- **自动转存**：到期后本息按到期日银行挂牌利率，再自动存一个同样的存期。适合不打算动这笔钱的客户，但也意味着利率按新的行情重新定。
- 这个选择购买后可以改，业务上还会在临近到期时给客户发提醒，引导客户决策（这是留存客户资金的关键触点——到期不承接，钱就流走了）。

## 五、客户购买的完整经历

从客户视角走一遍完整流程，开发人员借此理解每个环节的业务含义：

1. **逛货架**：客户从首页或理财频道进入存款专区，浏览产品，比较存期和利率。
2. **选产品**：点开某个产品看详情——利率、存期、起存金额、产品说明、常见问题。
3. **选付款账户**：确认从哪张卡的活期余额里扣钱，页面上会展示账户尾号和可用余额。
4. **填金额**：输入想买的金额，页面实时算出到期利息给客户看，这是促成下单的关键一屏。
5. **看提示、做确认**：阅读利率说明和产品提示并确认，可以选择是否关联自己的客户经理，有的活动还带视频回溯（方便日后回溯确认客户当时清楚自己买了什么）。
6. **提交等待结果**：几秒钟内出结果。
7. **看结果**：成功页展示这笔定期的完整信息——流水号、定期账号、金额、利率、起息日、到期日。客户可以截图或查询，这是交易的凭证。
8. **买完之后**：持仓列表里立刻能看到这笔定期，会收到购买成功的通知短信；如果参与了营销活动，还能抽奖或享受其他权益。

## 六、两种延伸购买方式

### 6.1 定期定投（签约式购买）

客户不一定有一大笔闲钱，但每个月有固定结余。定期定投就是"每个月自动帮你买一笔定期"：客户签约约定每月几号、扣多少钱、存多久，之后银行自动执行，每月形成一笔独立的定期合约。

- 适合工薪客群强制储蓄，业务价值在于培养客户长期存款习惯、稳定存款流入。
- 扣款日钱不够会按规则补扣或跳过，多次失败协议会终止并通知客户。
- 客户可随时暂停、恢复或解约。

### 6.2 代办购买

子女为年迈父母购买定期是常见的现实场景（父母的钱在父母账户，子女代为操作）。业务上要求验证亲属关系和被代理人的信息，全流程留痕。这类场景既要做营销友好（帮老人管钱是真实需求），也要守住合规底线（防止非授权操作他人资金）。

## 七、什么时候会买不成

业务上需要清楚常见的购买失败情形，以及应该给客户什么样的体验：

| 情形 | 客户侧表现 |
|------|-----------|
| 钱不够（可用余额小于购买金额） | 提示余额不足，告知缺口，引导先转入资金 |
| 金额低于起存门槛或不符合递增要求 | 输入时即时提示，不让客户提交后才发现 |
| 产品停售或额度卖完 | 提示产品不在售/已售罄，推荐同类在售产品 |
| 触发限额（单户/单日/账户类型限额） | 明确告知是哪一类限额，剩多少额度 |
| 证件过期 | 提示需先更新证件，指引到柜面 |
| 系统处理超时 | **绝不能说"失败"让客户重试**——钱可能已经扣了。提示"处理中，请稍后查询"，银行后台核实后给客户准确结果 |

最后一条是业务上最敏感的情形：客户的钱处于"不知道扣没扣"的状态。处理原则是宁可让客户多等一会儿查证，也不能引导重复购买造成重复扣款。客服和客户经理面对这类咨询时的标准口径也是"交易处理中，请以最终查询结果为准"。

## 八、与营销的联动

定期存款购买是营销活动最密集的触点之一：

- **客户经理归属**：客户购买时可选关联客户经理，或者由客户经理分享的链接/推荐码进入，业绩归属到对应经理和支行。这是存款营销考核的数据基础。
- **推荐人登记**：老带新场景，购买时登记推荐人，推荐人获得奖励。
- **购买后活动**：购买成功触发抽奖、加息券发放、权益赠送等，目的都是提升当下转化和下次复购。
- **到期承接营销**：定期到期前的提醒和再营销（推荐新产品、专属利率券），是保住存款不流失的最重要营销动作——存款到期日就是客户"用脚投票"的日子。

## 九、业务红线

最后是几条业务上的铁律，所有参与这个功能的人都必须清楚：

1. **利率必须锁定在合约里**：客户买的时候是多少就是多少，事后不能变。这是对客户的合同承诺。
2. **提示必须确认并留痕**：利率、存期、提前支取按活期计息这些关键信息，客户必须确认过，记录要能调出来。发生纠纷时这是银行自证的材料。
3. **宣传不能误导**：存款可以说保本保息（存款保险保障），但不能和理财混着展示让人分不清；预估收益必须标注以实际为准。
4. **可疑交易不允许重试**：见第七节，宁可查证，不可重复扣款。
5. **销售要可回溯**：部分场景要求双录或视频回溯，保证"客户清楚自己买了什么"可以被证明。
