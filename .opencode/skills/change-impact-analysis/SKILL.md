## 目标流程（待细化）

2. **影响分析**：变更 → 受影响 PRD 锚点 → 受影响 TP → 受影响 TC 的链式映射
3. **风险评估**：高风险变更（账务/权限/幂等类）强制纳入回归
4. **回归更新建议**：按「变更状态」列更新 05-test-cases.md（新增 / 修改 / 删除 / 保留），产出回归用例更新清单
5. **用户确认后更新**，最后进入用例最终评审
